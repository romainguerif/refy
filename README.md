# Refy

Board d'images de référence dans le navigateur, façon PureRef — pensé pour iPad et desktop.

**➡️ https://romainguerif.github.io/refy/**

- Ajoute des images (photothèque iPad, fichiers, glisser-déposer, coller)
- Déplace, redimensionne, pivote et passe en miroir tes images (gestes tactiles ou souris)
- Verrouille l'écran 🔒 pour décalquer directement sur la tablette (anti-veille inclus)
- Librairie de boards multiples, sauvegardés automatiquement dans le navigateur (IndexedDB)
- Backup / restauration en fichier `.refy.json` sur l'appareil
- Fonctionne hors-ligne (PWA) — ajoute-la à l'écran d'accueil de l'iPad

Une seule page HTML, zéro dépendance.
