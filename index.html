Refy

Ajouter : bouton ＋, glisser-déposer des fichiers, ou coller une image (Ctrl/Cmd+V).

Déplacer : glisse une image avec un doigt ou la souris.

Redimensionner : pince à deux doigts sur une image, ou tire les poignées d'angle.

Naviguer : glisse le fond pour te déplacer, pince ou molette pour zoomer.

Décalquer : le cadenas 🔓 fige tout l'écran (et empêche la mise en veille). Pour déverrouiller, maintiens le cadenas ~1 seconde.

Sauvegarde : le board est enregistré automatiquement dans le navigateur. 💾 exporte un fichier de backup sur l'appareil, 📂 le réimporte.

Clavier : Suppr = supprimer · F = tout afficher · Échap = déselectionner.
