Boards

L'icône en haut à gauche de la barre ouvre ta librairie : crée, renomme, supprime et change de board. Tout est enregistré automatiquement dans le navigateur.

Ajouter

Bouton + (photos), glisser-déposer, coller (Ctrl/Cmd V — images ou texte), et « Importer un document » dans le menu ··· pour les PDF et notes texte.

Crayon & texte

Le crayon dessine à main levée (couleur, épaisseur, annuler dans la palette) ; deux doigts naviguent pendant le dessin. Le T pose une zone de texte : double-tape dessus pour l'éditer, poignées pour la taille.

Manipuler

Un doigt : déplacer. Deux doigts sur un élément : taille + rotation (aimantée sur 0/90/180/270°). Poignées d'angle : taille. Poignée du haut : rotation. Dupliquer : bouton copie, Cmd/Ctrl D ou Alt+glisser. « Ranger le board » (G) aligne tout en grille — les annotations posées sur un élément le suivent. Sélection multiple : Maj+clic ou appui long, Maj+glisser sur le fond pour un rectangle, Cmd/Ctrl A pour tout prendre.

Décalquer

Les réglages d'une image (icône curseurs) offrent noir & blanc, contraste, opacité, extraction de contours et recadrage. Le cadenas fige tout l'écran et empêche la mise en veille — maintiens-le une seconde pour déverrouiller.

Checklists & notes

Checklist dans le menu ··· (L) : coche d'un tap, double-tape une ligne pour l'éditer, Entrée ajoute la suivante. L'onglet Notes de la librairie rassemble textes et checklists de tous les boards — tape pour y sauter.

Calendrier

Menu ··· ou C : un agenda local, sans synchronisation. Chaque événement appartient au board courant ; la vue Tous montre l'agenda de tous les boards. Un élément sélectionné au moment de l'ajout est épinglé à l'événement — l'épingle y ramène d'un tap. Les événements partent avec le board dans les backups.

Palette & liens

« Extraire la palette » dans les réglages d'une image pose un nuancier de ses couleurs (tape une couleur pour copier son code). Depuis la librairie, l'icône chaîne pose une carte-lien vers un autre board — double-tape pour l'ouvrir.

Présentation & export

Le mode présentation (P) masque toute l'interface, navigation seule. « Exporter en PNG » aplatit le board en une image.

Backup

Exporter/Importer dans le menu ··· : le board devient un fichier sur l'appareil ; l'import crée un nouveau board.
