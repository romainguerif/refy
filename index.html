Boards

L'icône en haut à gauche de la barre ouvre ta librairie : crée, renomme, supprime et change de board. Tout est enregistré automatiquement dans le navigateur.

Ajouter

Bouton + (photos), glisser-déposer, coller (Ctrl/Cmd V — images ou texte), et « Importer un document » dans le menu ··· pour les PDF et notes texte.

Crayon & texte

Le crayon dessine à main levée (couleur, épaisseur, annuler dans la palette) ; deux doigts naviguent pendant le dessin. Le T pose une zone de texte : double-tape dessus pour l'éditer, poignées pour la taille.

Manipuler

Un doigt : déplacer. Deux doigts sur un élément : taille + rotation (aimantée sur 0/90/180/270°). Poignées d'angle : taille. Poignée du haut : rotation.

Décalquer

Les réglages d'une image (icône curseurs) offrent noir & blanc, contraste, opacité et extraction de contours. Le cadenas fige tout l'écran et empêche la mise en veille — maintiens-le une seconde pour déverrouiller.

Calendrier

Dans le menu ··· : un agenda local, sans synchronisation — tout reste dans Refy.

Backup

Exporter/Importer dans le menu ··· : le board devient un fichier sur l'appareil ; l'import crée un nouveau board.
